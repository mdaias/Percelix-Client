# https://percelix.web.app/

📦 Parcelix

Parcelix is a modern courier and parcel delivery management platform designed to simplify parcel booking, tracking, delivery operations, and merchant management. The project provides a complete workflow for managing parcels from booking to final delivery.

🚀 Technologies Used

Frontend

- React.js — Building the user interface
- React Router — Client-side routing and navigation
- Tailwind CSS — Responsive and modern UI styling
- DaisyUI — Reusable UI components
- React Hook Form — Form handling and validation
- SweetAlert2 — Alerts and confirmation dialogs
- Axios / Fetch API — API communication
- Vite — Frontend development and build tool

Backend

- Node.js — JavaScript runtime
- Express.js — REST API and server-side application
- MongoDB — NoSQL database
- MongoDB Node.js Driver — Database connectivity and operations
- CORS — Cross-Origin Resource Sharing
- Dotenv — Environment variable management
- Nodemon — Development server auto-restart

Development & Tools

- Git — Version control
- GitHub — Source code hosting and collaboration
- VS Code — Development environment
- npm — Package management

✨ Key Features

- 🔐 User authentication and authorization
- 📦 Parcel booking and management
- 🚚 Courier and delivery management
- 📍 Parcel tracking
- 👤 Customer and merchant management
- 🛵 Rider/delivery personnel management
- 💰 Delivery charge and COD management
- 📊 Dashboard and parcel statistics
- 🔎 Parcel search and filtering
- 🗑️ Parcel deletion and management
- 📱 Responsive design
- 🔔 User-friendly alerts and notifications
- 🗄️ MongoDB-based data management
- 🔗 RESTful API integration


🎯 Project Goal

The goal of Parcelix is to provide a scalable and user-friendly digital solution for courier businesses, merchants, customers, and delivery personnel. It aims to make parcel booking, tracking, delivery management, and business operations more organized and efficient.

Status: In Development 🚧
